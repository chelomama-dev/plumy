# Plumy

AI-powered supplier invoice processing for Spanish accounting firms: upload invoices in any format, get validated and accounting-classified data ready to import into your accounting software, with human review only where needed.

> Work in progress. Learning-first project built with .NET 10, Angular, SQL Server and Azure.
